# INDI report (PDF)

Build the report with one command from any directory:

    indi_flight/report/pdf/build.sh            # figures, then LaTeX, then copy the PDF
    indi_flight/report/pdf/build.sh --no-figs  # skip the figure step

Result: `indi_flight/report/pdf/indi_report.pdf`.

## Requirements

- `lualatex` and `latexmk` (TeX Live with koma-script, libertinus, unicode-math, tcolorbox, pgfplots, cleveref, microtype)
- `python3` with `matplotlib` (only for the figure step)

## Layout

| Path | Role | Kind |
|---|---|---|
| `main.tex` | title page, abstract, contents, chapter order, bibliography | source |
| `preamble.tex` | class, fonts, colours, macros (`\param`, `\topic`, `\indidiagram`, `\indifigure`, `keyresult` box) | source |
| `chapters/*.tex` | one file per chapter and appendix | source |
| `diagrams/*.tex` | TikZ diagrams, included by `\indidiagram{name}{caption}{label}` | source |
| `figures/*.pdf` | plots, included by `\indifigure{name}{caption}{label}` | generated by `indi_flight/bench/report_figs/make_all.sh` |
| `build/` | LaTeX intermediate files (git-ignored) | generated |
| `indi_report.pdf` | final report | generated |

A missing diagram or figure prints a framed placeholder, so the build never stops for it.
The markdown chapters in `indi_flight/report/*.md` are the technical source of the numbers.
