# Pre-freeze review r1 (of 3): stage 5 INDI outer loop, code against specification

Scope: one interface, code vs. spec. Spec = `indi_flight/DECISIONS.md` D-F7-GROUND, D-STAGE-STALE (a)(b),
D-GAP + D-GAP-G510. Code: `src/modules/mc_indi_pos_control/{McIndiPosControl.cpp,.hpp,FailsafeSetpoint.hpp,
EkfResetDetect.hpp,IndiStageMode.hpp}`, `src/lib/indi_accel_control/indi_accel_control.{cpp,hpp}`.
Not reviewed: tests, results, other modules (stock `PositionControl.cpp:220-224` and commander

Checked and found consistent with the spec (no finding):
- **Modelled force:** `f_b = (0,0,-G u_model)` comes from the same delayed sample and filter, so `t_c = a_c - g` exactly (IAC:319-357).
- **Model-force cycles:** `mean_u` is invalid and b is held on landed, maybe_landed and model_acc (IPC:261-278). `useModelledForce` covers takeoff < flight, `ground_contact` and `maybe_landed` (IndiStageMode.hpp:48-51).
- **Stock velocity integrator:** reset on every armed cycle in position modes (IPC:995-997, 1044).
- **No residue:** no HandoverBlend and no hover-thrust sync remains. IPC:636-653 is the stock MPC_THR_HOVER constraint only.
- **Blend clamp:** kMaxBlend 0.5 is applied symmetrically (IAC:349). The sign `b = LP(u_model - u_meas)` is correct (a thrust loss gives b > 0). The gain `dt/(tb+dt)` is safe for any `dt >= kMinDt`. Anti-windup covers clamp, saturation and `mean_u >= 0.98`.
- **Divisions:** all guarded: `c >= kMinUpThrust`, `n_dir(2) < -0.1\|n\|`, `h > FLT_EPSILON`, `ht >= 0.05`, and `g_t, k_cmd > FLT_EPSILON`. The `sqrt` argument is clamped at 0. NaN inputs are rejected before use, and a non-finite `t_c`, `q_d` or thrust leads to Hold.
- **EKF reset detector:** latches correctly. A reset pending during Hold survives until the next run cycle.

## Verdict

REJECT for freeze as is. Fix F1, then fix F2-F4 or record them as spec amendments. After that: ACCEPT with fixes.
