## Finding 2 (BLOCKING): gate on instrument strength and misalignment
- Change: `fit_axis` returns `verdict = {criteria: [(name, value, pass)], passed}`; CLI (`main`) prints PASS/FAIL per criterion, then
  `IDENT PASS` / `IDENT FAILED`, exit code 1 on FAIL (also on a held regressor). ident_fit.py: GATE dict (top), verdict block at end of `fit_axis`, `main`.
- Criteria and thresholds (GATE): robust first-stage F >= 10; Hansen J/df <= 20; latency shift not on the scan boundary; 95 % CI/|G1| <= 0.15;
  excluded fraction <= 0.25; filter-chain gain match <= 0.01 (item 3).
- J choice and justification (honest): the HAC Hansen J is strongly oversized here. Correct synthetic data give J/df = 7.4, all five real logs
  give J = 103-105 on df 7 (J/df ~14.8), the same value as the deliberate 5-vs-15-tap mismatch (J/df 12.9) and the 17-sample delay (14.6). So J
  CANNOT separate the real logs from the mismatches; a threshold that fails the mismatch (<= 12) would fail every real log. J/df <= 20 is
  therefore only a gross-misalignment sanity limit (~1.35x the real logs, 2.7x the synthetic null). The mismatches are caught by the dedicated
  criteria (shift boundary, chain-gain match), not by J. The cause of J ~ 103 on real logs is OPEN (not investigated, likely HAC size distortion
  with 17 collinear lags; flag for the owner).

## Finding 3 (BLOCKING): HAC-robust first-stage F
- Change: `robust_first_stage_f` (ident_fit.py): Montiel Olea-Pflueger effective F, F_eff = pi'(Z'Z)pi / tr((Z'Z) V), V = HAC covariance of pi
  (Newey-West Bartlett, same lags as the second stage; hac 400 samples at 800 Hz = 200 rows at decimation 2). A Wald statistic was tried first
  and rejected: nearly collinear band-limited lags give an unstable V inverse (F ~ 1e13). The gate uses F_eff (`r["f"]`); the classical F
  stays as `f_classic`. Real logs: F_eff 216-8753 vs classical 448-13308, i.e. F_eff is 1.7-2x lower.
- Test with known answer: test_robust_f_known_answer: (1) white errors, 4 lags: F_eff/F_classic within 0.7-1.3; (2) x and z independent AR(0.99),
  true F ~ 1: classical F median 15.6 (> 10, spurious), F_eff median 1.0 (< 10, max 4.1).
- Broken once: HAC lags set to 0 in robust_first_stage_f -> the test failed (F_eff 15.6 vs 15.7, no longer < 10). OK.

  gain match over 1-60 Hz is also a gate criterion (<= 0.01), computed from the actual taps. Real G1 moved by +0.5..1.1 % through this
  change and the integer shift (see table).
