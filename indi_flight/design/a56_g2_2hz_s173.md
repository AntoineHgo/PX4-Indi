# A-56: G2 loop data at 1-4 Hz (S173)

Example, att pitch 800 s2 (the S164 plateau cell): 1.6 Hz -1.5 dB / -128.6 deg; 2 Hz -3.9 / -134.5; 2.5 Hz -6.5 / -141.8; 3.2 Hz -9.6 / -149.3.

Reading:
1. No INDI cell has max |S| above +3.4 dB in 1-4 Hz (threshold +6 dB); PM is 53-56 deg everywhere. No lightly damped 2 Hz mode appears in the frozen FRFs.
2. Phase never comes within 36 deg of -180 deg in 1.5-3 Hz. Where |L| is near 1 (attitude fc 1.4 Hz, rate fc 3-3.6 Hz) the phase is -125 to -135 deg.
3. The 0.2 Hz arg L = -171 deg (ax2_r800_s2, S164 FAIL) has |L| = +18.5 dB, so it is far below crossover and is not a 2 Hz issue.
4. PID comparison is impossible: no PID G2 margins exist (`results/g2_rate_table_s99.md` line 20 "NOT COVERED", GATES.md line 149 "not built (S102), deferred RC103"). The "PID does not oscillate" side rests on flights only.
5. Caveats: the FRFs are linear, small-signal and nominal-vibration (no harsh accel vibration, no hover->AUTO_LAND transition, not a nonlinear or saturation case). Bins are sparse (about 7 in 1-4 Hz) and rate bins start at 1 Hz; |S| peak at 4 Hz for rate is the grid edge. So this argues against a linear margin cause but cannot exclude a nonlinear, saturation or mode-switch cause at 2.0 Hz.
